# Ayur Veda Mantra --- Website Problem Statement

## 1. Project Overview

**Website Name:** Ayur Veda Mantra

Ayur Veda Mantra is an Ayurveda-focused website designed to present the
brand, explain its Ayurvedic treatments, showcase available products,
and make it easy for visitors to contact the business and place product
orders through WhatsApp.

The website will be developed **page by page**, with a strong focus on a
calm, premium, trustworthy Ayurvedic visual identity and a simple user
journey.

### Primary Pages

1.  Home
2.  About Us
3.  Treatments
4.  Products
5.  Contact Us

The website should be responsive and optimized for desktop, tablet, and
mobile users.

# 3. Core Problem

Many Ayurveda businesses struggle to communicate their treatments and
products online in a way that feels trustworthy, organized, and easy to
understand.

The website needs to solve this by creating a clear digital presence for
Ayur Veda Mantra where users can:

-   Understand what Ayur Veda Mantra offers.
-   Learn about the brand and its approach to Ayurveda.
-   Explore treatments by category.
-   Understand the purpose of individual treatments.
-   Browse available Ayurvedic products.
-   Contact the business easily.
-   Order products directly through WhatsApp without requiring a
    complicated e-commerce checkout.
-   Access the website comfortably from mobile devices.

The website should reduce friction between **discovering a
treatment/product** and **taking the next action**.

# 12. Product Ordering Flow

Each product should have an **Order on WhatsApp** button.

When clicked, WhatsApp should open with a pre-filled message.

### Required Message Format

> I want "\[Product Name\]"

The message should be sent to:

**9074255833**

The implementation should dynamically replace `[Product Name]` with the
actual product name.

### Example

For a product called **Ayurvedic Hair Oil**, the pre-filled WhatsApp
message should be:

> I want "Ayurvedic Hair Oil"

The WhatsApp CTA should be highly visible on the product detail/card.

# 17. Accessibility & Usability

The website should follow basic accessibility and usability principles.

Requirements include:

-   Sufficient color contrast
-   Descriptive image alt text
-   Keyboard-accessible interactive elements
-   Clear button labels
-   Logical heading hierarchy
-   Readable font sizes
-   Forms with clear labels
-   Visible focus states
-   Avoid relying only on color to communicate meaning

------------------------------------------------------------------------

# 18. SEO Requirements

The website should be structured with SEO in mind from the beginning.

### Technical SEO

-   Clean URL structure
-   Semantic HTML
-   Proper heading hierarchy
-   Unique title tags
-   Meta descriptions
-   Image alt text
-   Optimized images
-   Mobile responsiveness
-   Fast page performance
-   XML sitemap
-   Robots.txt
-   Canonical URLs where necessary
-   Proper internal linking

### Content SEO

Treatment pages/sections should use natural, user-focused language
around relevant Ayurveda and wellness search intent.

Avoid keyword stuffing.

The website should prioritize **useful information and search intent**
over excessive keyword repetition.

------------------------------------------------------------------------

# 19. Performance Requirements

The website should be lightweight and fast.

Key requirements:

-   Optimize images
-   Use responsive image formats where appropriate
-   Avoid unnecessary JavaScript
-   Minimize third-party scripts
-   Lazy-load below-the-fold images where appropriate
-   Keep animations subtle and purposeful
-   Prioritize Core Web Vitals
-   Ensure WhatsApp CTA remains reliable even on slower mobile
    connections

# 25. Success Criteria

The website will be considered successful when:

1.  Visitors immediately understand what Ayur Veda Mantra offers.
2.  Treatments are easy to discover and understand.
3.  Products are easy to browse.
4.  Users can order any product through WhatsApp with one clear CTA.
5.  Product WhatsApp messages contain the correct product name
    automatically.
6.  Contact information is easy to find.
7.  The website feels authentic to Ayurveda rather than generic.
8.  The design is consistent across every page.
9.  The website works smoothly on mobile and desktop.
10. Pages are structured properly for search engines.
11. The site loads quickly and provides a clean user experience.
12. No unsupported health claims are introduced into the website
    content.
